# English Flow v2.6.0 — звіт про реліз

## Мета
Випустити стабільний фікс-реліз: виправити чотири баги юзера, зробити рейтинг чисто хмарним і закріпити нову схему версій (звичайний реліз = +0.1, масштабне оновлення = ціле число).

## Зміни
- **TODAY «блимає» і показує 0** — виправлено на рівні причини: у проєкті три різні схеми id слів (статичні `1..50`, згенеровані `n1..n333`, хмарні notion_id-UUID). Прогрес у БД ключується by notion_id, а слова на екрані часто приходили з іншою схемою → «Вивчено: 0» і подвійний блик поки слова добираються. Додано `progKey` + індекс «текст слова → notion_id» (`getWordIdByText`), тому підрахунки «Слів у базі / Вивчено / На повторення SRS» тепер стабільні незалежно від того, яке джерело слів відмалювалося першим.
- **Вхід у завдання викидав на реєстрацію** — виправлено: 401 більше не робить автоперехід на onboarding. Замість цього модалка «Сесію завершено» з кнопкою «Увійти знову», урок тримає власний inline-ретрай.
- **«Сесію завершено» в гостьовому режимі** — виправлено: `cloudPull` для гостя не ходить у мережу взагалі, тому жодного 401 на старті.
- **Рейтинг — тільки Хмарний рейтинг** — прибрано merge локальних профілів; Leaderboard показує виключно `cloudLeaderboard()` (назва «Хмарний рейтинг»).
- **Версія 2.6.0** — скрізь: `const VERSION` у App.jsx, `package.json`, анонс, changelog, e2e-тест версії.
- Дрібні правки: охайна кнопка у ConfirmModal для помилок з дією, коментарі в Leaderboard.

## QA покриття сторінок (зміни v2.6.0)
1. Home — стабільні підрахунки статистики, без подвійного блику, правильні «Вивчено / SRS».
2. Learn / Lesson — вхід у урок без викидання на реєстрацію; при 401 — модалка з «Увійти знову».
3. Гостьовий режим — «Увійти як гість» без помилки «Сесію завершено».
4. Leaderboard — лише Хмарний рейтинг, без локальних профілів.
5. About — версія v2.6.0, changelog, анонс.

## Ручні перевірки / реальне середовище (ще потрібні)
- **Деплой і жива перевірка на Vercel** — не зроблено: фікси існують лише локально, їх треба залити на GitHub (робить користувач вручну) і потім додеплоїти.
- **Гостьовий клік-тест** — натискання кнопок у браузері ще не виконано (планувалося сьогодні, відкладено).
- **Не встановлені env-змінні** у Vercel: `ADMIN_SECRET`, `SYNC_SECRET`, `WEBAUTHN_RP_ID`, `WEBAUTHN_ORIGIN`, `VITE_REALTIME_URL` → passkeys вимкнені, скриптовий Notion-синк і realtime недоступні.
- `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` оголошені, але **код їх не використовує** — залишки старої архітектури, можна прибрати.
- Перевірити реально: урок, завершення сесії → зріст «Вивчено» та «SRS» (мене сьогодні підтвердили: рахує лише завершені сесії — так і задумано).

## Відомі обмеження
- Realtime-WS неможливо хостити на Vercel (окрема служба).
- Неон-пулинг (PgBouncer) не підтримує LISTEN/NOTIFY через звичайний DSN.
- Клік-тест без бекенду бачить очікувані мережеві помилки на `/api/*` — це норма.

## Ідеї для наступного релізу
- Додати «Сторінка WebAuthn/passkey» з перейменуванням, видаленням і recovery-кодами.
- Додати офлайн-нотатку або кеш словника для стабільної статистики без мережі.
- Прогрес-бар «Вивчено» на Home з привʼязкою до завершених сесій (робимо наочною логіку «тільки завершені»).
- Очистка env: прибрати невикористовувані `VITE_SUPABASE_*`.
- Автоматичні skрини десктоп/таблет/мобілка.
